# Module integration gaps

The selected public references are immutable source objects, often historical. Their availability is not an installed-state survey, module test rerun or present-default readiness verdict. Requirements below remain open until actual owning boundaries and exact qualification evidence establish them.

| Module or role | Initial limited integration gap | Later full acceptance |
| --- | --- | --- |
| swarma-user-manager | Native initial/boot/audit inventory, qualified existing generation, launcher/FD3/observe/stop/quiet absence and receiver interlock | Full PC2 currentness/custody and strict physical-release behavior |
| swarma-keymaker | Allocated/implemented/qualified typed purpose 6, real active caller registration, protected association, enrollment/bootstrap endpoints and actual custody adapters | Narrowed caller delegation, message signing/certification and expanded registry/custody |
| swarma-credential-broker | Full runner/foreign-peer/time/store rollback and real-account activation audit, dedicated-service topology, worker status client and all-lease horizon | Signed binding/grant, freshness and automatic security final-material fence |
| swarma-dispatcher | Protected policy/currentness, one effect/reservation/receipt, existing-generation seam, closed executor entry and authenticated durable output/outcome | Broader binding/grant/revocation and session/workspace adapters |
| swarma-witness | Serving, actual consumer adapters, synchronous independent custodian, use/recovery/time and lifetime old-instance exclusion | Full archive/audit/readers, additional consumer scopes and production independence |
| swarma-owner-registry | No selected deployment role in the limited local policy path | Isolated online signer, actual witnessed publication/current head, snapshot/revocation/currentness and independent completion/use custody |
| waggle | No required dependency for a bare local worker/lease; a signed-result selection imports its real gates | Unchanged signed Matrix bytes, receiver replay/effect currentness and agreed external-root currency delta |
| Registrar/carrier | Selected register-after-active caller path does not require registrar deployment | Production clock/remote audit, operated-server expiry/deactivation fixes and isolated admission qualification |
| Session/workspace role | Bounded immutable-input/text-output seam is distributed across dispatcher, launcher and runner; no general service imported by name | Actual additional runtime dependencies require separate accepted publication/qualification |
| Pool, memory and federation | Outside initial selection | Separate owner decisions and their own hostile-work/current-authority contracts; stored evidence never becomes authority |

There is no qualified integrated run, installed release tuple, passing end-to-end harness or completed revocation claim supplied by this repository. See [status](status.md) and [gates](integration-gates.md).
