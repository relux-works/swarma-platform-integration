# Evidence and runtime status

This repository supplies generic requirements, selected public source pins and renderable dependency diagrams. No integrated runtime, root installation, host state, credential operation, live canary, owner signature or production activation is established here. Lack of evidence does not prove another operator has no process.

| Evidence class | Supported claim | Unsupported inference |
| --- | --- | --- |
| Public object pin/hash | Selected source bytes at an exact public identity | Moving-default readiness, release, installed binary or native qualification |
| Requirement and dependency document | Required semantics and open owning boundaries | Implemented service or accepted timing budget |
| DOT/SVG | Reviewable logical relationship and renderer output | Deployed placement, independent custody or live data flow |
| Initial limited integration | Nine required qualification packages defined in the gates | No executed package credited: 0/9 |
| Later full acceptance | Fifteen required acceptance areas retained | No executed area credited: 0/15 |

Documentary checks and preparation privacy controls give bounded artifact evidence only; they are not runtime tests or killed runtime mutants. No public test harness is supplied. Source landing, proposal acceptance, owner authorization, installed qualification and activation require their own exact evidence. Planned permission expiry, security revocation, lease invalidation and token lifetime remain distinct.
